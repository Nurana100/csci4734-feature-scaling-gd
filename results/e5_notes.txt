E5 regularization (linear regression, scale ratio 100, rho = 0.5, lambda = 0.1). With the equivalent penalty P = A^T A, every scaler reaches the same optimal objective f = 0.1315, which is the same as plain ridge on the raw data, so scaling then only changes how fast gradient descent gets there and not the answer. With the naive penalty (plain L2 on the scaled weights) the result depends on the scaler: 0.5661 for standardize, 3.9271 for min-max and 0.6904 for whitening, because each scaler stretches the weights differently, so the same lambda means a different amount of shrinkage in raw units. Min-max is hit the hardest, because dividing by the range makes its weights the largest, so the penalty pushes them hardest, which is why fair comparisons between scalers must use the equivalent penalty.
